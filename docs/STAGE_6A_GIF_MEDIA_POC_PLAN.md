旧 `a8e9ded` 和 `docs/FFMPEG_GUI_CANDIDATE_AUDIT.md` 的 No-Go 保留为历史源码审计；本规划取代其作为后续媒体 PoC 的执行口径，但不自动推翻其中的风险结论。

## 用户任务与首版范围

用户任务：

- MP4 / MOV 转 GIF
- GIF 重新压缩
- 两个或更多任务的本地批量队列

首版任务参数：

- 起止时间
- 输出尺寸
- FPS
- 循环开关
- 质量 / 体积倾向
- 输出目录

首版任务状态：

- 等待
- 运行
- 成功
- 失败
- 取消
- 百分比进度与可读错误信息

首版预设：

| 预设 | 意图 | 说明 |
|---|---|---|
| 高清 | 优先画质 | 不承诺最小体积 |
| 8MB 倾向 | 优先尝试较小体积 | 不保证低于 8MB，结果必须显示实际大小 |
| 快速预览 | 优先处理速度 | 用于快速确认片段和构图 |
| 原尺寸 | 保留输入尺寸 | 仍受 GIF 编码能力和输出限制约束 |

明确不做：逐帧编辑、多轨时间轴、关键帧、通用视频编辑、转场、字幕、音频、通用图层系统、自研编码或自研量化。

## FFUI 隔离 PoC 边界

- 候选前端保留 FFUI 的 Vue UX，但只作为当前 Tauri 应用的独立内部窗口或隔离前端入口；不得形成第二个 Tauri app，也不要求用户额外安装。
- 主 React 工作台与媒体 PoC 状态完全隔离：不读取或写入 `BoardDocument`、品牌设置、素材裁切、FocusSession、Render Plan 或未保存工作状态。
- 只规划安装包内唯一 FFmpeg / FFprobe sidecar；不得下载、复制或打包第二份媒体运行时。
- 优先复用 FFUI 已有的队列、进度、取消、进程终止、错误和结果 UX；不从零重写相同的队列/取消/结果界面。
- 打开或关闭隔离窗口不得影响 Logo 与版式工作台、其未保存状态或当前工具入口。

## PoC 验收矩阵

| 类别 | 必测项 | 通过条件 |
|---|---|---|
| 平台 | macOS arm64、Windows x64 | 两个平台均可离线启动 PoC 且可完成受控任务 |
| 路径 | 中文、空格和普通 ASCII 路径 | 输入、输出、错误信息与取消均正确处理 |
| 输入 | MP4、MOV | 至少各识别一个受控 fixture |
| 转换 | 一个 MP4 → GIF | 起止、尺寸、FPS、循环、调色板/质量参数均进入实际命令 |
| 队列 | 两个任务连续执行 | 顺序、进度、成功结果和单项失败状态正确 |
| 取消 | 运行中取消 | 进程终止、任务状态为取消、后续队列行为明确且不损坏结果目录 |
| 恢复 | 受控失败后继续 | 错误可见，后续任务和新任务仍可运行 |
| 隔离 | 打开/关闭内部窗口 | React Logo 工作台与未保存状态保持不变 |
| 离线 | 断网环境 | 不触发首次下载、云服务或远程 API |

## 技术决策与停止条件

Stage 6B 前必须确认：

1. FFUI 的许可证允许当前用途下的修改、内嵌与分发，并完成第三方声明。
2. Vue 运行时与现有 Tauri 2 壳可以隔离共存，不引入第二个应用壳或破坏 React 工作台。
3. 唯一 FFmpeg / FFprobe sidecar 的来源、版本、许可证、macOS/Windows 架构、校验值、构建注入与更新策略可审计。
4. 前端、sidecar、Windows 安装包、macOS DMG、安装后目录和峰值内存的实际增量可记录，且没有无法解释的重复运行时。
5. FFUI 现成 UX 能覆盖队列、进度、取消、错误和结果；如果需要重写这些核心 UX，停止 Stage 6B。

立即停止 Stage 6B 的条件：

- 需要第二个 Tauri app、用户额外安装或首次联网下载。
- 无法注入唯一 bundled sidecar，或需要重复打包 FFmpeg / FFprobe。
- 许可证、跨平台支持、中文/空格路径、进程取消或离线运行任一关键项无法验证。
- 为完成首版而需要自研编码、调色板、量化、时间轴、图层或通用视频编辑。
- 隔离窗口会污染主工作台状态、未保存任务、Render Plan、导出或更新链路。

## Stage 6B 最小文件与依赖清单

在 `docs/STAGE_6B_BACKEND_GATE.md` 的全部前置条件满足后，才允许按以下最小清单建立 PoC：

- 一个隔离窗口/前端入口及关闭清理逻辑。
- 一个媒体任务适配层，仅承接队列、参数、进度、取消、错误和结果，不接触主工作台业务状态。
- Tauri 2 命令层的最小 sidecar 调用、进程终止和结构化任务事件。
- 唯一 FFmpeg / FFprobe sidecar 的受审计构建资源与校验记录。
- FFUI 必需的 Vue 运行时和最小构建配置；不得引入第二个 Tauri 壳。
- macOS arm64 与 Windows x64 fixture、路径、取消、离线和隔离回归测试。

任何超过该清单的需求，先回到产品边界、依赖审计和用户确认。
