# 产品边界

## 一句话定位

品宣物料工作台是一个轻量、本地、面向内部流程的文件处理工具。它负责把成熟能力整合成稳定流程，不负责重新发明编辑器、编解码器或算法。

## 核心程序负责

- 主视觉与已设计图导入
- 多尺寸画板、裁切与安全区检查
- Logo / CPR 资源、语种与版型规则
- 批量导出、命名、体积限制和复核
- 固定对象的简易自定义构图
- 桌面文件写入、诊断、自动更新和分发

## 核心程序不负责

- 通用图片编辑
- 自由图层与文档系统
- 任意元素创作
- 视频剪辑
- 多轨时间轴
- AI 生成或训练
- 自研编解码、压缩、水印或指纹算法
- 为实验功能打包大型独立运行环境

## 自定义构图

### 固定对象

| 对象 | 可见控制 | 拖动 | 等比缩放 | 旋转 | 新增/删除 |
|---|---|---|---|---|---|
| 底图 | 始终显示 | 否 | 否 | 否 | 仅替换 |
| 游戏 Logo | 是 | 是 | 是 | 否 | 否 |
| 公司 Logo | 是 | 是 | 是 | 否 | 否 |
| CPR | 是 | 是 | 是 | 否 | 否 |

除表中能力外，一律视为范围外。

### 交互原则

- 位置与大小优先在画布直接操作。
- 精确数值放在当前选中对象的属性区。
- 语种、显示、导出格式属于参数控制。
- 导入与导出是明确主操作。
- 不同时提供多套等价控制。拖动已经能解决位置时，不再保留横移/纵移滑块；必要时只保留 X/Y 数字精调。
- 面板只显示当前任务需要的信息，不展示通用编辑器工具。

### 技术边界

Fabric.js 可以承担：

- 固定对象选中
- 命中区域
- 拖动
- 四角等比缩放
- 选框视觉反馈

Fabric.js 不承担：

- 正式渲染与导出
- 业务版型规则
- Logo / CPR 语种解析
- 文件保存
- 图层系统
- 编辑工程模型

正式输出必须继续走现有 Render Plan，避免预览和导出产生两套结果。

## 未来工具模块

### GIF / 动图

允许整合成熟离线引擎，范围仅限：

- 尺寸
- 帧率
- 色彩数量或质量
- GIF / Animated WebP 转换
- 单段起止裁切

不得追加多段剪辑、转场、字幕、音频、滤镜、图层或关键帧。

### 普通水印

范围仅限：

- 思源黑体 Regular
- 基础文字水印
- 单点或平铺
- 大小、颜色、透明度、角度和间距
- 批量导出

### 实验性功能

- 抗 AI 去水印干扰
- 像素隐形指纹

仅在找到许可证清晰、离线、跨平台且无需大型运行时的成熟方案后进入验证。不得自研，不承诺绝对防删除或绝对可追溯。

## 复杂编辑需求

当前工作台不提供复杂编辑器。

遇到文字排版、多图层、蒙版、滤镜、选区、画笔、路径、复杂合成等需求时，默认处理方式是交给 Photoshop、Affinity Photo、Photopea 类外部成熟工具，而不是扩展当前程序。

未来若必须接入，只允许独立可选工具或外部调用，不得直接进入核心安装包。

## 依赖决策门槛

新增第三方方案前必须回答：

1. 许可证是否允许内部修改、打包和分发
2. 是否完全离线
3. Windows 与 macOS 是否都能运行
4. 是否需要额外运行时、模型权重或系统服务
5. 是否可以整体复用而不是重写
6. 能否隔离在模块内，不污染现有状态和导出链路
7. 安装包增加多少
8. 移除或替换是否容易

任一关键项无法确认时，不进入主分支。
