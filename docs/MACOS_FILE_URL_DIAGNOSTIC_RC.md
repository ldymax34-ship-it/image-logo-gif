# macOS 文件 URL 诊断候选包（0.1.35-rc.1）

## 状态

**未修复、未通过验收。** 此候选包只增加本机临时诊断观测，用于定位 macOS WKWebView 中本地图片 `asset://` URL 无法加载的问题；不修改图片加载器、权限、Fabric、GIF、批量模板或更新器行为。

## 使用

1. 打开 `品宣物料工作台 Diagnostic`，进入“水印与追溯”。
2. 通过系统文件选择器导入 PNG/JPG（建议再测试含中文和空格的路径），或选择图片 Logo。
3. 右侧“RC 文件 URL 诊断”显示完成后，点击“复制诊断报告”；若剪贴板不可用，展开最新报告并手动复制。

报告只保留在当前应用会话内，包含本机路径及转换 URL；不会自动落盘、上传或写入应用日志。报告记录 dialog 路径、plugin-fs、`convertFileSrc`、HTMLImage、只读 fetch 与 Fabric 探针的时间顺序和结果。
