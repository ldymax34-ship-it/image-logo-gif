# 品宣物料工作台 UI 规范

## 目标

这是一个高频使用的本地桌面工具。界面应紧凑、安静、可扫读，优先服务素材检查、画板调整和导出，不采用营销网页或玻璃拟态风格。

## 字体与排版

- 字体栈：`Inter, system-ui, -apple-system, BlinkMacSystemFont, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`。
- 基础正文固定为 `14px / 1.5`；辅助信息为 `12px / 1.4`。
- 区块标题为 `16px / 1.3`；应用标题为 `20px / 1.3`。不使用负字距。
- 按钮、输入、下拉与正文使用同一基础字号。数字、尺寸和文件名可用等宽字体，仅用于提高扫描效率。

## 令牌

- 间距只使用 `4 / 8 / 12 / 16 / 20 / 24 / 32px`。
- 圆角只使用 `6 / 8 / 10px`；胶囊标签可用 `999px`。
- 面板使用极淡 `1px` 边框和轻微阴影，不叠加卡片中的卡片。
- 颜色、字号、间距、圆角、阴影和动效时长应优先来自 `src/styles/tokens.css` 与 `src/styles/theme.css`。

## 色彩与层级

- 应用背景为浅灰；主要工作面板为白色；画布区可使用中性灰。
- 冷蓝只用于主操作、选中态、键盘焦点与关键状态。
- 危险操作使用单独的红色文字和浅色背景，不与主操作混用。
- 信息层级优先用背景、边框、留白和字体权重表达，阴影只能辅助。

## 控件

- Button：最小高度 34px；文本按钮用于明确命令，图标按钮必须有 `aria-label` 与悬停提示。
- Tabs：用于互斥模式；同一时间仅一个选中项，不以页面大面积切换动画掩盖内容变化。
- Input / Select：统一 34px 高，聚焦时显示冷蓝描边；输入状态不应改变布局。
- Toggle：仅用于开/关状态；不要用按钮模拟二元开关。
- Panel：页面三栏是固定工作区，不使用悬浮卡片化页面分区。
- Modal：用于聚焦编辑、确认和导出。右上角提供关闭；有未保存改动时需确认放弃；底部有取消与主操作。
- ConfirmDialog：只用于覆盖、删除或丢弃未保存改动，标题应直接描述后果。

## 动效与模糊

- 交互反馈使用 `120ms`，弹窗使用 `220ms` 的轻微透明度、向上 `6px` 和 `0.98 -> 1` 缩放。
- 禁止整页淡入、卡片飞入和大范围动画。
- 禁止在应用背景、三栏面板、画布或大图上使用 `backdrop-filter`。
- 仅在将来确有必要的小型浮层使用模糊，并必须做低性能降级；当前版本统一不使用。

## 响应式

- 桌面三栏是优先形态。
- `900px` 及以下允许面板纵向排列，弹窗改为上下布局；文字、画布和控件不得重叠或溢出。
- 不用视口宽度缩放字体；通过网格和可用空间调整布局。
