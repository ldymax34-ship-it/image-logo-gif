# 品宣物料工作台 UI 规范

## 目标

这是高频使用的本地桌面生产工具。界面采用中性深灰工作台，优先服务素材扫描、画板调整和导出；不使用营销网页、SaaS 卡片、玻璃拟态或装饰性视觉。

## 排版与间距

- 正文固定 `13px / 1.45`，属性标签与辅助信息 `12px / 1.4`，页面标题 `14px`，应用标题 `16px / 1.25`。
- 面板水平内边距统一 `12px`。
- 同组控件间距 `6–8px`，大组之间 `12–16px`。
- Label 使用固定宽度或上下结构，避免控件随文案跳动。
- 只使用 `4 / 6 / 8 / 12 / 16 / 24px` 间距档位。

## 色彩与层级

- 应用背景为中性深灰，左右面板略亮，中央画布区略深。
- 三栏面板之间使用 `1px` 低对比分隔，不做悬浮卡片和大阴影。
- 分组依靠标题行、分割线和留白；不在面板内继续套卡片。
- 冷蓝只用于选中、焦点和主操作，危险操作使用红色。
- 禁止渐变、玻璃模糊、彩色装饰和大面积品牌色背景。
- 默认控件使用透明或低对比边框；只有 hover、selected、focus、warning、error 提升边框强度，不使用辉光。

## 控件

- Button、Select、Input 统一 `32px` 高；属性区紧凑控件与图标按钮为 `28px`，点击区域不得更小。
- Hover、Active、Focus、Disabled 状态必须通过统一 tokens 表达，状态变化不改变布局。
- Selected 同时使用 `1px` 主色边框、轻微背景和文字变化，不能只依赖颜色点。
- Warning / Error 使用独立边框、轻背景和文字；禁止用 glow 表达错误。
- Toggle 只表示二元开关；分段控件只表示互斥模式。
- 折叠区使用紧凑标题行和右侧展开箭头，展开内容不额外套卡片。
- 所有图标按钮必须有 `aria-label` 和 `title`。

## 参考边界

- OpenPencil 是属性面板、字段、分段控件、工具栏密度和交互状态的主参考；不引入其源码、Vue 或通用编辑器模型。
- Figma 只作为画布交互语义参考，不复制整体视觉。
- OpenDesign HTML 只参考深色层级和留白；排除大范围辉光、重玻璃模糊、展示型 Dashboard 卡片、大圆角和装饰渐变。

## 总览

- 总览按素材分组，每组标题显示缩略图、文件名、原始尺寸和画板数量。
- 分组默认展开，使用较大垂直留白和 `1px` 分割线区分，不套厚重卡片。
- 当前素材组使用左侧冷蓝标记；当前画板同时由 `assetId + specId` 决定。
- 素材列表点击后滚动到对应分组，其他素材仍保留可见。

## 动效与响应式

- 交互反馈 `120ms`，弹窗 `220ms`，禁止整页淡入和卡片飞入。
- 禁止在应用背景、面板、画布或大图使用 `backdrop-filter`。
- 桌面优先三栏；`960px` 以下允许纵向排列，`900px` 检查弹窗与总览无横向溢出。
- 不随视口缩放字体，通过网格和可用空间调整布局。
