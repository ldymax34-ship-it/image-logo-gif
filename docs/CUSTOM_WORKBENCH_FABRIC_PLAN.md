# 自定义构图 Fabric.js 收口计划

## 目标

使用 Fabric.js 替换当前自定义构图中手写的 Pointer 拖动、透明命中层和缩放交互，但不把模块扩展成通用编辑器。

本计划只解决已有固定对象的操作稳定性，不增加新功能。

## 固定范围

画布中永远只有：

1. 一张锁定底图
2. 一个游戏 Logo
3. 一个公司 Logo
4. 一个 CPR

允许：显示/隐藏、选择、拖动、等比缩放、精确数值、复位、导出。

不允许：旋转、多选、分组、任意新增对象、文字、额外图片、图层面板、滤镜、蒙版、画笔、自由变形、通用撤销系统。

## 实施前置：包体审计

在安装 Fabric.js 前先完成 `docs/PACKAGE_SIZE_AUDIT.md`：

- 记录当前 Windows / macOS 构建产物体积
- 定位当前接近 200MB 的主要来源
- 明确是否已经打包额外运行时、重复资源或未使用依赖
- 记录 `node_modules` 不是发行包体积，必须以真实安装包和安装后目录为准

Fabric.js 接入后重复同一审计，给出增量。

若任一发行包增加超过 10MB，停止合并并报告。

## 架构原则

```txt
Fabric.js 画布操作层
        ↓
固定对象状态适配层
        ↓
现有 gameOffset / gameScale / companyOffset / companyScale / CPR 状态
        ↓
现有 Render Plan
        ↓
正式预览与导出
```

Fabric.js 只负责交互，不负责最终导出。

## 对象约束

### 底图

- 不可选中
- 不可移动
- 不可缩放
- 不参与对象列表 UI
- 替换底图时重建画布尺寸与固定对象映射

### 游戏 Logo / 公司 Logo / CPR

- 只能通过程序创建
- 不能复制、粘贴、删除或新增
- 禁止旋转控制柄
- 禁止边中点自由拉伸，只保留四角等比缩放
- 不允许离开当前约束边界
- 显示开关关闭时隐藏，但保留状态
- 语种切换时替换资源，不改变当前位置和缩放

## UI 收口

### 画布

- 点击对象显示选框
- 拖动调整位置
- 四角控制点等比缩放
- 点击空白取消选中
- 保留参考线与吸附，但只在确实稳定时接入；不得为了吸附重写一套复杂系统

### 属性区

只显示当前选中对象的属性：

- 名称
- 显示开关
- 游戏 Logo 的语种
- 缩放数值
- X / Y 数字精调
- 复位

没有选中对象时显示：

- 参考线
- 吸附
- PNG / JPG
- 导出

删除横移、纵移滑块。位置日常通过拖动完成，X/Y 数字仅用于精调。

高级描边、阴影、发光不得成为本轮 Fabric.js 接入的一部分。保持现状或另行审查，禁止顺手扩展。

## 状态与导出

- Fabric 事件结束后，写回现有业务状态。
- React 状态是业务真源；Fabric 对象不是持久化真源。
- 切换语种、显示状态或底图后，应由业务状态更新 Fabric 对象。
- 导出不得直接调用 Fabric `toDataURL` 或 Fabric Canvas 导出。
- 继续使用现有 `buildBoardRenderPlan`、`renderBoardToCanvas`、`exportBoardImageWithinLimit` 和桌面保存流程。

## 推荐实施步骤

1. 完成包体审计，不改业务代码。
2. 在隔离组件中验证 Fabric.js 能在 Tauri WebView2 与 WKWebView 运行。
3. 只放入一张底图和一个 Logo，验证坐标、缩放和高 DPI。
4. 建立 Fabric 坐标与 Render Plan 状态的纯函数映射。
5. 补映射测试后再接入三个固定对象。
6. 替换手写 Pointer dragRef 与透明 `custom-drag-layer`。
7. 删除重复位置滑块，仅保留 X/Y 数值精调。
8. 验证语种替换、显示开关、参考线、吸附和导出。
9. 对比接入前后的安装包体积。
10. 完成 Windows 与 macOS 实机验证后，才允许进入 Preview 分发。

## 必须测试

### 纯函数测试

- Fabric left/top/scale 转业务 offset/scale
- 业务 offset/scale 反向恢复 Fabric 对象
- 不同查看缩放下坐标不漂移
- 高 DPI 下位置一致
- 约束边界 clamp
- 语种替换不改变变换

### 交互验证

- 游戏 Logo 拖动与缩放
- 公司 Logo 拖动与缩放
- CPR 拖动与缩放
- 对象切换选中
- 点击空白取消选中
- 显示开关保留状态
- X/Y 数值与画布双向同步
- 替换底图后状态可预期

### 导出验证

至少选取横版、方图、竖版各一张：

- 画布显示位置
- Render Plan 预览位置
- 最终导出位置

三者应在允许误差内一致。不得以肉眼差不多代替映射测试。

## 不得顺手完成

- 不重构批量设媒工作台
- 不改自动更新、签名或发布流程
- 不新增编辑器模块
- 不加入文字、额外图片或图层
- 不处理 GIF、水印、像素隐形指纹
- 不换状态管理框架
- 不引入设计系统或大型 UI 框架

## 完成定义

只有同时满足以下条件才算完成：

- 手写拖动与透明命中层已移除
- 三个固定对象可稳定拖动、等比缩放和精调
- 正式导出仍走现有 Render Plan
- 预览与导出位置一致
- 现有核心测试、单元测试和构建通过
- Windows 与 macOS 实机验证通过
- 包体增量已记录，且未超过门槛
- 没有新增范围外功能
